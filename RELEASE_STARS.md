# Обновление: Stars, каталог, админка

## Реальное состояние
- Интеграция создания счетов Telegram Stars, проверка pre_checkout и successful_payment реализованы. Реальный Telegram API в тестах не вызывался.
- Курс 1 Star = 1,1 монеты. Пакеты 10/50/100/250/500/1000 Stars дают целые монеты без округления. Произвольные суммы не поддерживаются.
- Клиентский callback paid НЕ начисляет деньги: начисляет только сервер по webhook, один раз на платёж. Уже принятый Telegram платёж зачисляется даже после бана пользователя или отключения новых оплат.
- Админка: баланс с причиной, баны, промокоды с лимитами и сроками, обращения, аудит, последние 100 счетов Stars (ожидающие/оплаченные).
- Все 20 составов и шансы переработаны. Серверные кейсы 12–47 позиций; клиентские 3–6, ограничены существующим каталогом. Некоторые цены повышены, поскольку раньше цена кейса была ниже любого приза. Детали в catalog-audit.txt.
- Расчётный RTP примерно 89–92% по указанной стоимости товаров. Это не гарантирует окупаемость или возможность продать предмет за эту цену. Наличие, цены и права на выдачу товаров у поставщиков не подтверждены.
- Открытие, апгрейд, инвентарь и выдача товаров НЕ реализованы в этой сборке. Поэтому Stars выключены по умолчанию. Не включайте приём денег до готовности этих частей, поддержки возвратов и правил сервиса.
- Автоматические возвраты и сверка с getStarTransactions пока не реализованы. Для запуска нужен отдельный план обработки возвратов и платежных обращений /paysupport.

## Установка
1. Сделать резервную копию существующей SQLite базы. Не заменять её новой пустой базой.
2. Заменить файлы проекта, запустить python server.py.
3. Настройки среды: MESHCASE_BOT_TOKEN, MESHCASE_ADMIN_IDS (числовые Telegram ID через запятую), MESHCASE_WEBHOOK_SECRET (случайный секрет), MESHCASE_DB_PATH (относительный путь на постоянном диске).
4. Через Telegram Bot API setWebhook настроить HTTPS URL https://ВАШ-ДОМЕН/api/tg/webhook с secret_token, равным MESHCASE_WEBHOOK_SECRET. allowed_updates должен включать message и pre_checkout_query. Если у бота уже есть другой webhook, нужен единый маршрутизатор: Telegram поддерживает только один webhook на бота; не заменяйте существующий без интеграции обработчиков.
5. Только после завершения серверной игры, выдачи, проверки возвратов и контрольной оплаты можно включить MESHCASE_STARS_ENABLED=1. До этого интерфейс сообщает о недоступности пополнения.
6. Настроить кнопку Mini App в BotFather на HTTPS URL приложения. Проверить вход обычным игроком и администратором.
