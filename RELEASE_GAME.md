# Админка и серверная игра

Обновление добавляет открытия кейсов, постоянный инвентарь, продажу предмета за его номинал во внутренних монетах и апгрейд одного предмета в более дорогой. Кнопка открытия находится перед составом кейса. Инвентарь, апгрейды и последние операции — в профиле.

## Администратор
По умолчанию admin_ids.txt содержит Telegram ID 1842295433. Права проверяются сервером после проверки подписи Telegram. Переменная MESHCASE_ADMIN_IDS имеет приоритет: на существующем хостинге задайте 1842295433, если переменная уже есть. Пустое значение переменной отключает всех администраторов. render.yaml также обновлён. Админка: баланс с причиной, баны, промокоды, поддержка, аудит (существующие функции).

## Механика
- Открытие: списание цены и создание предмета в одной SQLite-транзакции; выбор secrets.randbelow по опубликованным шансам с точностью 0,001 процентного пункта.
- Продажа: предмет расходуется, номинал начисляется во внутренних монетах, без вывода денег.
- Апгрейд: исходный предмет расходуется всегда. Шанс = floor(стоимость исходного × 900000 / стоимость цели) / 10000 процентов; цель строго дороже, минимальный шанс 0,01%. Множитель 90% — новое выбранное правило, показано до подтверждения. Успех даёт один новый предмет, неудача не даёт ничего.
- Клиент не задаёт цену, баланс, шанс или результат. Владение, бан и достаточность средств проверяются сервером. Результат и ключ операции сохраняются в БД. Повтор того же запроса возвращает прежний результат без нового списания.
- При сетевой неопределённости ключ хранится в браузере. В профиле кнопка проверки повторяет именно сохранённый запрос. Не очищайте данные браузера до проверки результата.
- История баланса содержит операции, включая апгрейды с нулевым изменением монет. Последние 30 игровых результатов доступны в профиле.

## Ограничения и запуск
Это локальное обновление, не подтверждённый деплой. Перед заменой файлов сделайте резервную копию БД. Используйте постоянный диск; Render Free с эфемерным диском не подходит для хранения балансов. Таблицы добавляются автоматически без удаления старых аккаунтов.

Внешняя выдача донатов, конфигов, токенов и других товаров НЕ реализована. Предмет в инвентаре не означает покупку в магазине сервера. Возвраты Stars также не реализованы. Stars остаются выключены по умолчанию; не включайте реальные платежи без проверки каталога, исполнения заказов, возвратов и требований платформы/законодательства. Есть мгновенный результат открытия, но нет полноценной рулетки/анимации апгрейда.

Тесты: test_game.py (4 группы: конкурентные повторы, собственность/продажа, успех/неудача апгрейда, средства/бан/админ), test_miniapp.py (6), test_stars_catalog.py (5), test_balance.py (2) прошли. JavaScript синтаксис проверен QuickJS. Chromium не запускается в окружении; внешний вид и реальный Telegram не проверены.
