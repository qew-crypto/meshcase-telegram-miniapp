# Информационные команды бота

Изменения: /start, /help, /support; безопасная обработка некорректного URL поддержки и входящих данных.

server.py обновлён: webhook вызывает bot_greeting.handle_start вместо прежнего приветствия bot_messages.welcome. Информационные команды завершаются ответом ok; прочие обработчики не изменены.

Настройки окружения:
- MESHCASE_WELCOME_TEXT — необязательный текст приветствия.
- MESHCASE_SUPPORT_URL — HTTPS-ссылка на контакт поддержки.
- MESHCASE_SUPPORT_TEXT — необязательные инструкции обращения.

При отсутствии контакта бот прямо сообщает, что контакт не настроен и обращение не создано. Команды не создают тикеты, не пересылают сообщения администраторам и не обрабатывают выводы.

Проверка: python -m unittest test_bot_greeting test_bot_support -v
11 тестов прошли локально. Отправка в Telegram проверена только подменой bot_api, не живым ботом.

Для установки: сохранить резервную копию bot_greeting.py в целевой версии, заменить его файлом из пакета, добавить настройки окружения и перезапустить приложение. Убедиться, что webhook целевой версии вызывает handle_start. Затем проверить /start, /help и /support в личном чате.

Проверка живого Telegram и развёртывание сайта выполняются отдельно. Другие файлы проекта и денежные механики не менялись.
