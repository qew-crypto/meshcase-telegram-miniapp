# MeshCase · Telegram Mini App

Исходники Mini App, сайта и Python-сервера. Для Mini App нужна HTTPS-публикация сервера и бот Telegram; локальное открытие `index.html` не заменяет сервер.

## Запуск локально

```sh
MESHCASE_BOT_TOKEN=your_bot_token python server.py
```

Откройте `http://localhost:8000/miniapp.html`. Для входа через Telegram нужно открыть Mini App из бота по HTTPS-адресу, указанному в BotFather. Подробности: [MINIAPP_SETUP.md](MINIAPP_SETUP.md).

**Текущий статус:** Mini App поддерживает авторизацию Telegram, профиль, серверный баланс промокодов, поддержку и админ-функции. Оплата Telegram Stars, открытия кейсов и апгрейды в Mini App **не подключены**: нельзя принимать реальные платежи или выдавать призы, пока игровая логика не перенесена и не проверена на сервере. Старые страницы сайта и их локальная игровая логика — отдельный прототип на localStorage.

Не публикуйте токен бота, данные пользователей и базу SQLite. Перед коммерческим использованием проверьте права на изображения и названия сторонних проектов.
