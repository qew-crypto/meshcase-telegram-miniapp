# MeshCase — Telegram Mini App v2

Мобильный интерфейс Telegram, серверный баланс, админка и поддержка с перепиской. Python 3.10+, без обязательных pip-зависимостей.

## Запуск

```sh
python server.py
```

Хостинг: Dockerfile из корня сборки, либо Python с командой выше. Не Node.js. Используется PORT (по умолчанию 8000). Проверка сервера: GET /healthz.

Настройте переменные в защищённых настройках хостинга:

- `MESHCASE_BOT_TOKEN` — токен бота, не коммитить и не отправлять в чат.
- `MESHCASE_PUBLIC_ORIGIN` — точный публичный адрес вида `https://example.com`, без пути.
- `MESHCASE_ADMIN_IDS` — **числовой Telegram ID владельца**, например `123456789`. Несколько ID через запятую. Без переменной нет администраторов. Ник Crypa228 и username не дают прав. Свой ID можно увидеть в профиле после входа через Telegram.
- `MESHCASE_DB_PATH` — относительный путь SQLite, например `data/meshcase.sqlite3`. По умолчанию `meshcase.sqlite3` в корне, чтобы сохранить совместимость со старой сборкой. Абсолютные пути и выход из проекта запрещены.

В BotFather задайте URL кнопки меню / Main Mini App: `https://example.com/miniapp.html`. Главная `/` тоже открывает Mini App. Старые HTML-страницы перенаправляются на него. Авторизация проверяет Telegram initData на сервере. Просто открыть URL в браузере можно для просмотра каталога, но не для входа.

## ВАЖНО: сохранность базы и обновление

Перед обновлением сделайте согласованную резервную копию текущей SQLite (через SQLite backup API или при остановленном сервере; при WAL нельзя копировать только основной файл на работающем сервере).

Новая сборка не содержит базу. Не заменяйте существующую базу пустой. Таблицы и колонки добавляются автоматически без очистки аккаунтов, балансов, промокодов и обращений. Старые ответы поддержки сохраняются первым ответом в переписке.

SQLite должна храниться на **постоянном диске**. На эфемерном диске бесплатного хостинга данные пропадут при redeploy/restart. Для production настройте постоянное хранилище; пример относительного пути внутри проекта — `data/meshcase.sqlite3`. Если меняете путь, сначала перенесите старую базу согласованным способом. Запускайте один экземпляр приложения с одним постоянным диском, не несколько независимых копий SQLite.

render.yaml содержит базовую конфигурацию free-плана, **без постоянного диска**. Не используйте её с важными балансами без настройки хранения.

## Что работает

- Telegram-вход с серверной проверкой подписи, адаптивная навигация, кнопка Назад, тактильный отклик.
- Каталог 20 кейсов, фильтры, изображения, карточка подробностей.
- Серверный баланс монет, промокоды, история начислений и списаний. Баланс не берётся из localStorage.
- Админка: поиск игроков, начисление/списание монет с причиной, баны и снятие банов, создание/включение/выключение промокодов, сроки и лимиты, история активаций в виде счётчика, ответы поддержки, журнал действий.
- Поддержка: новые обращения, цепочка сообщений, ответы из админки, закрытие/повторное открытие, обновление каждые 15 секунд при открытом экране поддержки.
- Проверка прав на сервере: обычный пользователь не может менять баланс, читать чужие обращения или использовать админские API. Бан блокирует операции и чтение обращений даже после повторного входа; собственный профиль остаётся виден с причиной бана.
- Изменения баланса и использование промокодов выполняются в транзакциях. Промокод одному пользователю — один раз. Параллельные запросы не превышают общий лимит.

## Что ещё НЕ подключено

**Открытие кейсов, апгрейды, выдача призов и реальные платежи отключены в Mini App.** Каталог сам по себе не означает готовность игровых операций. Монеты MeshCase не являются Telegram Stars. У старого сайта остаются исходники, но старые страницы больше не доступны как отдельный интерфейс. Старые localStorage-балансы и аккаунты по паролю не конвертируются в Telegram-балансы автоматически.

До публичной эксплуатации с реальными ценностями нужны серверная игровая логика и выдача, интеграция платежей с идемпотентностью, резервные копии, мониторинг и инфраструктурные лимиты запросов. Поддержка не отправляет уведомлений в личные сообщения бота; ответ читается в Mini App.

## Проверки

```sh
python -m py_compile server.py tg_backend.py
python test_miniapp.py
```

6 групп интеграционных тестов: роли и Origin, баланс и баны, конкурентная активация промокодов, доступ к обращениям и диалог, журнал и история, статические файлы/картинки/шансы. Тесты используют отдельную временную базу и вымышленные ID, не production-данные.

JavaScript проверен парсером QuickJS. Браузер Playwright не запустился в текущем окружении — визуальная проверка и тест в реальном Telegram обязательны после размещения.

## Проверка после деплоя

1. Откройте приложение через Telegram; убедитесь, что ID в профиле ваш.
2. Добавьте этот ID в MESHCASE_ADMIN_IDS, перезапустите сервис, откройте приложение заново.
3. Со второго аккаунта проверьте поддержку, ответ админа и промокод.
4. В админке начислите/спишите небольшое количество монет и проверьте историю. Проверьте бан/снятие бана второго аккаунта.
5. Перезапустите сервис и проверьте, что данные остались.

Сборка подготовлена локально. Она сама не обновляет GitHub, BotFather или работающий хостинг.
