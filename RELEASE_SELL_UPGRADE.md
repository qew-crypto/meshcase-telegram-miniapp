# Продажа всех предметов и новый раздел апгрейда

- POST /api/tg/game/sell_all: продажа снимка inventory_ids в одной транзакции. Проверка владельца, состояния, уникальности ID, блокировки пользователя и повторов request_id. Если хотя бы один предмет уже использован, продажа целиком отклоняется.
- Результаты открытия: продажа только призов данного открытия. Профиль: продажа всего загруженного доступного инвентаря. Подтверждение количества и суммы во внутренних монетах.
- Апгрейд: самостоятельная реализация по структуре публичной страницы https://dashcase.xyz/upgrades (HTML получен). Две выбранные карточки, центральный круг шанса, сетки выбора, поиск цели, ×2/×5/×10/30%/50%. Адаптивная компоновка на узких экранах. Код и бренд DashCase не копировались.
- 40 тестовых запусков unittest прошли (включая повторные унаследованные тесты Games), JavaScript синтаксис проверен QuickJS. Браузер не запускается в этой среде; реальный Telegram и визуальный результат не проверены.
- GitHub и хостинг этим изменением не обновлены. Внешняя выдача не менялась.
