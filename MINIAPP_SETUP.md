# MeshCase Telegram Mini App · текущий этап

Запуск: `MESHCASE_BOT_TOKEN=<токен бота> python server.py`; нужен HTTPS-домен, указанный в настройках Mini App у BotFather, URL `https://ваш-домен/miniapp.html`. В Telegram открывать кнопкой Mini App бота. Не публикуйте токен в ZIP, Git или JS. Для продакшена нужен reverse proxy HTTPS, резервное копирование SQLite, защита от DDoS и мониторинг.

Подпись и срок действия Telegram initData проверяются сервером; автоматическая регистрация по Telegram ID. Только Telegram ID **1842295433** управляет промокодами и отвечает на обращения через вкладку «Админ». Код на баланс начисляет монеты в отдельном серверном балансе; код на % проверяется в форме пополнения. Старый ник/пароль Crypa228 НЕ даёт доступ к администрированию Mini App.

**Платежи Звёздами НЕ включены**: кнопку и API счетов блокируем, потому что старые кейсы, апгрейд и инвентарь ещё используют localStorage и подделываются клиентом. Игровой экран Mini App показывает каталог кейсов без открытия; серверный баланс не подключён к старой игре. Пожалуйста, не подключайте платежи/выдачу до переноса и проверки серверной игровой логики. Код расчёта инвойса/вебхука — заготовка, не production-ready. Для будущего webhook необходимо секретное значение MESHCASE_WEBHOOK_SECRET и setWebhook на `https://ваш-домен/api/tg/webhook` с `secret_token`.

Старые страницы `index.html`/`game.js` — отдельный прототип, не Mini App и не связаны с балансом Telegram. Не используйте их с реальными платежами.
